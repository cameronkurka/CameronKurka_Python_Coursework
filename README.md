# Python Programming Projects

## Overview

This repository contains a collection of Python projects completed through coursework at The University of Alabama. These projects demonstrate my development in Python programming, data analysis, file processing, debugging, and problem-solving.

The coursework progressed from foundational programming concepts to more complex applications involving modular programming, object-oriented concepts, file handling, and data cleaning.

As a Business Cybersecurity student, these projects helped strengthen my programming foundation and develop skills applicable to cybersecurity automation, data analysis, and technical problem-solving.

## Projects

### Coffee Shop Management
A menu-driven coffee shop management application that processes customer transactions and applies business logic for inventory, pricing, discounts, taxes, change, and staffing decisions.

**Key Concepts:** Python fundamentals, conditional logic, loops, user input, business logic

### Culverhouse Station Game
A multi-module terminal game featuring multiple activities and an energy management system. The project uses separate Python modules to organize game functionality and maintain player state.

**Key Concepts:** Modular programming, functions, object-oriented programming, input validation, randomization, state management

### Flower Shop Calculator
A Python application that calculates flower shop orders using user input, variables, constants, arithmetic operations, and pricing logic.

**Key Concepts:** Variables, constants, user input, calculations, Python fundamentals

### ROT13 File Utility
A file-processing utility that encodes and decodes text using ROT13 while performing file operations and text analysis.

**Key Concepts:** File I/O, string manipulation, functions, error handling, text processing

### Sales Data Cleaner
A data-cleaning and analysis project using Python and Polars to process retail sales transaction data. The application handles missing and invalid values, corrects data types, identifies duplicate transactions, calculates sales metrics, exports cleaned data, and generates a summary for data-quality review.

**Key Concepts:** Python, Polars, data cleaning, CSV processing, data validation, duplicate detection, data analysis
